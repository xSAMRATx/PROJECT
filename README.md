# PROJECT — Front-end design collection

A collection of static websites and page clones I built while learning front-end development.
Each folder is a separate project made with **HTML and CSS** (a few pages also use a little JavaScript). No build tools or frameworks are needed.

## Projects

| Folder | What it is | Open this file |
| --- | --- | --- |
| `Amazon_clone` | Amazon-style shopping home page with product category cards | `Amazon_website.html` |
| `Google_Home_Page` | Google search home page clone | `Google_Home_Page.html` |
| `Youtue_clone` | YouTube home page clone | `indet.html` |
| `Parallax_website` | Parallax scrolling website with full-screen nature sections | `Project3_parallax_website.html` |
| `Restaurant_Website` | "Spicy King" restaurant website | `Restaurent_website.html` |
| `Restaurant_wesite` | Restaurant landing page with menu section | `index.html` |
| `University_website` | University website with courses and campuses sections | `University_website.html` |
| `Music_website` | "myTunes" music streaming landing page | `index.html` |
| `blog_website` | "GreatZone" blog with a home page and a post page | `Home.html`, `Post.html` |
| `Documentation_project` | Technical documentation page (JavaScript docs layout) | `index.html` |
| `Job-Application_From` | Job application form | `Project-2_Job-Application_From.html` |
| `Landing_page` | Personal developer landing page | `Landing_page.html` |
| `Protfolio_Website` | Personal portfolio page | `Protfolio_Website.html` |
| `Protfolio2_Website` | Portfolio template with projects section | `Index.html` |
| `PAGE` | Simple biography page | `Project_1.html` |
| `Simple_page` | Simple single page layout | `Project.html` |

## How to view

1. Clone the repo:
   ```bash
   git clone https://github.com/xSAMRATx/PROJECT.git
   ```
2. Open any project folder and double-click the HTML file listed above, or open it with the VS Code **Live Server** extension.

## Tech

- HTML5
- CSS3 (Flexbox, positioning, background images, simple animations)
- A little vanilla JavaScript in `Protfolio2_Website` and `blog_website`
